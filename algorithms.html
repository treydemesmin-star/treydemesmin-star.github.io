Planned enhancement

I plan to model prerequisite relationships with adjacency lists and use Kahn’s topological sort to produce a valid prerequisite order. The enhancement will reject missing references and self prerequisites and detect cycles. This will be an ordering feature, not a semester scheduling system.

Validation evidence to be added

Tests will include chains, disconnected courses, multiple prerequisites, cycles, and invalid records. I will verify each prerequisite occurs before its dependent and measure scaling on generated catalogs. Expected graph processing is O(V + E) with average constant-time hash lookups.
